# IPES 8 Channel Analog Data Logger – DWIN Android HMI

Dedicated **8-channel only** Android HMI for the IPES 8 Channel Analog Input Data Logger, targeting the DWIN DMG80480T050_32WTC 5-inch 800×480 capacitive-touch Android terminal.

## Included
- CH1–CH8 live values
- Eight live trend graphs
- Per-channel name, unit, scale and offset
- USB serial logger input at 115200 baud
- Main/battery source indication and battery telemetry fields
- Local CSV recording
- 800×480 landscape / immersive HMI layout
- GitHub Actions ARM64 release APK build

GitHub Actions artifact name: `IPES_8CH_DWIN_Android_v1.0_APK`.
